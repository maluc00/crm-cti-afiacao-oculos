# CTI Pro CRM (`crm-cti-afiacao-oculos`)

Plataforma ERP/CRM e BI 100% Local-First (Node.js + SQLite + WebSocket LAN) para gestao de oficinas de precisao optica e afiacao/cutelaria, acessivel simultaneamente no PC e no Celular via rede local.

## Documentacao e Execucao
- Governanca de Engenharia: `AGENTS.md`
- Plano das 6 Fases: `ROADMAP.md`
- Registro Tecnico: `DEVLOG.md`
- Inicializacao Windows: execute `iniciar-cti.bat` (ou `npm start`)
- Testes Automatizados: `npm test`
